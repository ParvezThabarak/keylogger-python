# keylogger-python
This project is an educational key event monitoring application developed using Python.
It captures keyboard events (Pressed, Held, Released) and stores them in text and JSON formats.

## Features
- GUI using Tkinter
- Keyboard event monitoring using pynput
- Logs stored in logs.txt and logs.json
- Designed remind for cybersecurity learning

## Technologies Used
- Python
- Tkinter
- pynput

## Ethical Notice
This project is strictly for educational and lab use only.
Do not use on systems without permission.

## How to Run
1. Install dependencies:
   pip install pynput
2. Run:
   python keylogger.py
